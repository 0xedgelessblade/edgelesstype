# edgelesstype documentation / 文件中心

edgelesstype 是 Apple silicon Mac 的開源語音輸入 App，支援本機 Whisper、選用 OpenAI 語音辨識、繁體中文輸出、文字校正與中翻英。適用 macOS 26 以上；目前以原始碼建置安裝。
