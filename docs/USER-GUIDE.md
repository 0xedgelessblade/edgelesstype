# edgelesstype 使用說明書 / User guide

這份文件供已安裝的使用者閱讀。第一次安裝請看 [AI 安裝指南](INSTALL_WITH_AI.md)；平台需求是 Apple silicon M 系列 Mac、macOS 26 以上。

[文件中心](README.md) · [常見問題](FAQ.md) · [疑難排解](TROUBLESHOOTING.md)

## 開始第一句聽寫

1. 開啟私人使用目錄裡的 **Local Edgeless Type.app**，等待本機模型就緒。
2. 點選你要輸入文字的空白輸入框。
3. 短按 **Fn**，聽到開始音後說話。
4. 再按 **Fn** 結束錄音。面板會顯示目前處於上傳、辨識或文字處理。
5. 確認文字只出現一次。若沒有自動貼入，可按 **⌘V** 手動貼上；App 不會代按 Enter 傳送訊息。

第一次的麥克風、輔助使用與輸入監控由本人核准。請確認授權的是私人目錄裡的 App，不是公開建置副本。模型未就緒或權限尚未完成時，不能當成安裝成功。

取消會停止本次等待並忽略晚到的結果，不讓舊文字突然貼入。已送到雲端的請求不保證能撤銷服務端工作或費用。

## 本機辨識與雲端辨識

**Whisper（本機）** 是預設選項，不需要 API 金鑰。Small 與 Large-v3 Turbo 可從選單選擇；不要把模型名稱當成速度保證。

**GPT Transcribe（OpenAI 雲端）** 需要使用者選用、同意上傳錄音，並在 App 的安全欄位儲存自己的 OpenAI 金鑰。雲端辨識與後續文字服務商分開設定；只儲存金鑰不會自動開啟音訊上傳。不要把金鑰貼給 AI 或放進 GitHub。

**Gemini Transcribe（Google 雲端）** 用 Google 的語音轉文字模型辨識，會自動去掉「呃」「嗯」等填充詞，並把字典詞送去輔助辨識；辨識完仍照原設定校正。**Gemini 一趟式辨識＋校正（Google 雲端）** 則把錄音和字典一次交給 Gemini，直接拿回已校正的文字，省掉第二次校正請求；中翻英仍照翻譯服務商處理。兩者都沿用 Google 金鑰，需要先同意上傳錄音；單次錄音約 7 分鐘以內。

雲端辨識等超過 5 秒時，辨識框會浮出「改用本機 · Fn」：點它或再短按一次 Fn，就取消雲端、改用本機 Whisper 辨識同一段錄音並貼上。本機結果沒有雲端校正，標點可能較少。雲端若回覆失敗，會先自動重送一次；仍失敗時紅色提示有「重試」，錄音只留到提示關閉為止。

## 字典與文字校正

在字典新增常用詞的正確寫法。選用「根據整句上下文校正」時，轉寫文字與相關詞彙會交給設定的文字服務商。這裡的「上下文校正」是整句文字校正，與下一節「讀取輸入框附近文字」是兩個不同選項。

校正會依整句語意、句法與發音可能性判斷同音字和詞語邊界；不使用固定替換。合理原句與無法確定的多義句應保留，但模型結果仍需使用者判斷。這項能力需要啟用文字校正，不能把「錄音上下文」開關當成同一功能。

中翻英需要已設定的雲端文字服務。一般本機聽寫可以不設定任何雲端金鑰。

## 錄音上下文：自行開啟

到「語音辨識…」找到「錄音上下文」設定卡：

- **錄音上下文**：預設關閉。開啟後，在開始錄音時讀取游標附近少量純文字，提供辨識參考；不截圖、不讀整份文件。
- **允許傳送至 OpenAI／Google**：獨立且預設關閉，主開關開啟後顯示。選用雲端辨識但未允許傳送時，不擷取上下文；Gemini Transcribe 模式本身不接受上下文文字。
- 按 **儲存設定**，下一次錄音生效。關閉主開關並儲存，也會撤銷上下文的雲端傳送同意。

不支援、安全密碼欄位、焦點改變或逾時時會略過，不阻擋錄音。原始上下文不保存為檔案；若它進入辨識結果，後續啟用的雲端校正或翻譯仍可能收到。詳見 [隱私說明](../SECURITY.md)。

## 沒有貼上或一直等待

先確認游標仍在原輸入框。文字預覽存在時可手動 ⌘V；尚在處理時可點 × 取消後再試。不要反覆觸發貼上或在測試時按 Enter。自動貼上與預覽收框不是所有 App 都有同等驗證，請看 [相容性界線](COMPATIBILITY.md)。

Fn 沒反應時，確認私人 App 的輸入監控與輔助使用權限，退出後重新開啟；不要把重設所有 App 權限當成更新步驟。仍失敗請按 [症狀排錯](TROUBLESHOOTING.md)。

## 更新與隱私

更新只從公開原始碼部署程式到私人使用目錄，沿用自己的簽署憑證與識別碼。既有字典、設定、模型及金鑰不回傳 GitHub。請依 [本機更新指南](LOCAL-SIGNING.md) 操作，不重新初始化既有目錄。

回報問題只描述操作、固定錯誤類型與版本。不要附錄音、上下文、逐字稿、私人畫面或原始日誌，也不要把真實內容留下當測試資料。
